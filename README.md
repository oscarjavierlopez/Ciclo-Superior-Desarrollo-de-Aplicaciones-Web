# Ciclo Formativo de Grado Superior: Desarrollo de Aplicaciones Web (DAW)

Este repositorio reúne las prácticas, ejercicios y proyectos desarrollados durante el ciclo formativo de **Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.

---

## Tecnologías y Herramientas

### Frontend
- **Lenguajes:** HTML5, CSS3, JavaScript (ES6+)
- **Frameworks / Librerías:** React, Bootstrap, Tailwind CSS, Angular

### Backend
- **Lenguajes:** PHP, Javascript, Python
- **Frameworks:**  Laravel, Express, Django

### Herramientas & Entornos
- **Control de Versiones:** Git, GitHub
- **Entornos:** Linux, MySql, Apache, Nginx, Docker 

---

## Estructura de Módulos / Asignaturas

El repositorio está organizado por los principales módulos formativos del grado:

- `EntornoCliente/` – Interfaces dinámicas, interactividad, manipulación del DOM y consumo de APIs con JS.
- `EntornoServidor/` – Desarrollo Backend, APIs REST, comunicación con bases de datos, lógica de negocio.
- `Despliegue/` – Configuración de servidores web, dominios, protocolos de red y contenedores.
- `DiseñoInterfaces/` – Usabilidad (UX/UI), accesibilidad web (WCAG) y diseño responsive.
- `Frameworks/` – Utiización de frameworks y librerías para acelerar el desarrollo de aplicaciones web y estandarizar el código.

---

## Proyectos Destacados del Ciclo

* **[Proyecto Gestión Eventos Castilla y León](./EntornoCliente/sitioWeb)**: Aplicación web desarrollada con express.js, react y MySQL para facilitar la suscripción de usuarios a eventos culturales de la comunidad autónoma de Castilla y León .
